# موسوعة الأدوية — إعداد د. عبدالمجيد الماخذي

تطبيق أندرويد (Flutter) لموسوعة أدوية ثنائية اللغة، يعرض **الاسم العلمي أولاً** مع الأسماء
التجارية متداخلة تحته (كل اسم تجاري له شركة، دولة، قوة/تركيز، وصورة).

## المزايا المُنفّذة في هذا الإصدار الأولي
- قاعدة بيانات محلية (SQLite) تعمل بالكامل **بدون إنترنت**.
- بحث فوري بالاسم العلمي أو التجاري (عربي/إنجليزي).
- شاشة دواء: الاسم العلمي أولاً، مقدمة، آلية العمل، التداخل الدوائي، ثم قائمة الأسماء التجارية.
- إضافة دواء ومنتج تجاري يدوياً، مع **إدراج صورة** من الكاميرا أو المعرض.
- **استيراد CSV** لإدخال بيانات كبيرة دفعة واحدة (راجع `sample_import_template.csv`).
- نطق الأسماء بالإنجليزية فقط (Flutter TTS) — بدون نطق عربي كما طُلب.
- بيانات تجريبية أولية (Amoxicillin وParacetamol) لتوضيح البنية.

## ما لم يُبنَ بعد (يحتاج تطوير إضافي حسب الخطة التي ناقشناها)
- البحث بالصورة (OCR + مطابقة).
- قراءة الباركود.
- مزامنة سحابية / جلب بيانات من openFDA أو DailyMed أو RxNorm.
- لوحة تحكم إدارية منفصلة ونظام مراجعة صيادلة.
- استيراد Excel (.xlsx) مباشرة (حالياً CSV فقط).

## الطريقة الأسهل: بناء APK في السحابة بدون تثبيت أي شيء (موصى بها)
تم تجهيز المشروع بملف `.github/workflows/build-apk.yml` يقوم ببناء APK تلقائياً عبر GitHub Actions:

1. أنشئ حساب مجاني على github.com إن لم يكن لديك.
2. أنشئ مستودع (Repository) جديد فارغ.
3. ارفع محتويات هذا المجلد (`pharma_app`) إلى المستودع (عبر الموقع مباشرة برفع الملفات، أو عبر git).
4. اذهب إلى تبويب **Actions** في المستودع — سيبدأ البناء تلقائياً (أو اضغط "Run workflow" يدوياً).
5. بعد اكتمال البناء (حوالي 5-10 دقائق)، افتح النتيجة (run) ثم حمّل الملف من قسم **Artifacts** باسم `pharma-app-release-apk` — بداخله `app-release.apk` جاهز للتثبيت على أي جهاز أندرويد.

هذه الطريقة لا تحتاج منك تثبيت Flutter أو Android Studio إطلاقاً؛ كل البناء يتم على خوادم GitHub مجاناً.

## أو: بناء ملف APK على جهازك مباشرة
لتشغيله كتطبيق مثبّت محلياً تحتاج Flutter SDK مثبتاً على حاسوبك:

```bash
# 1) تثبيت Flutter (إن لم يكن مثبتاً): https://docs.flutter.dev/get-started/install
flutter --version

# 2) داخل مجلد المشروع
cd pharma_app
flutter pub get

# 3) تشغيل على جهاز/محاكي متصل
flutter run

# 4) بناء APK جاهز للتثبيت
flutter build apk --release
# الملف الناتج: build/app/outputs/flutter-apk/app-release.apk
```

## تنبيه مهم
هذا الإصدار **نموذج أولي (MVP)** وليس تطبيقاً طبياً معتمداً. قبل الاستخدام الفعلي يجب
مراجعة صيدلانية للبيانات، والتأكد من ترخيص أي صور أو بيانات شركات تُضاف، والإشارة بوضوح
داخل التطبيق أن المعلومات تعليمية ولا تغني عن استشارة الطبيب أو الصيدلي.
